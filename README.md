# Менеджер продуктов

## Назначение приложения

Менеджер продуктов - приложение для учёта продуктов  и их срока годности.
Данные сохраняются в файл `products.json` и загружаются при следующем запуске.

## Используемые технологии

- Python `3.14.6`
- Flet `1.0.3`

Требуемая версия Python: 3.10 или новее

### Основные классы

- `Product` - базовый класс продукта: идентификатор, название, количество, методы увеличения и уменьшения количества, получения описания и состояния
- `RegularProduct(Product)` - обычный продукт без срока годности
- `PerishableProduct(Product)` - скоропортящийся продукт со сроком годности, который сам определяет своё состояние
- `ProductStorage` - загрузка и сохранение продуктов в `products.json`
- `ProductManager` - список продуктов, добавление, удаление,изменение количества, фильтрация, сохранение
- `ProductCard` - визуальное представление одного продукта средствами Flet
- `ProductApp` - интерфейс приложения: форма, фильтры, список карточек,
  обработчики событий

### Наследование

`RegularProduct` и `PerishableProduct` наследуются от `Product` и вызывают
`super().__init__(...)` в своих конструкторах, чтобы заполнить общие поля
`product_id`, `name` и `quantity`. Наследники переопределяют методы базового
класса: `get_state()`, `get_type_name()`, `get_description()`, `to_dict()`

### Полиморфизм

Код вызывает методы `get_state()`, `get_type_name()`, `get_description()`
одинаковым образом для объектов разных классов, а нужную реализацию выбирает
сам объект. Например, фильтр «Скоро испортятся» в `ProductManager` сравнивает
`product.get_state()` со значением `STATE_SOON`, а карточка показывает
`get_type_name()` и `get_state()`, не зная, какой именно класс перед ней
(кроме одной проверки `isinstance` там, где нужно определить наличие срока
годности)

### Инкапсуляция

Обязанности разделены между классами: `Product` отвечает за своё состояние,
`ProductManager` - за коллекцию объектов и операции над ней, `ProductStorage` -
за чтение и запись JSON, `ProductApp` и `ProductCard` - за отображение и
события. Глобального списка продуктов нет, обработчики событий только получают
данные из полей и передают работу менеджеру

### Абстракция

Общие свойства и поведение продуктов (идентификатор, название, количество,
увеличение и уменьшение количества, описание, состояние) описаны в базовом
классе `Product`
